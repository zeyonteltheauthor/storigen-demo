# grade-along-web

Proxies Grade Along onto `https://gradealong.com` from the existing GitHub Pages site (`https://zeyonteltheauthor.github.io/storigen-demo`). The github.io team link is not changed, so the teacher passcode box stays there. Schools on gradealong.com see only work email and invite sign-in (the passcode box is hidden unless `?team=1` is in the URL).


`/demo` and `/demo/` redirect to `/grade-along/?demo` so the public demo keeps the same asset paths as the app.
